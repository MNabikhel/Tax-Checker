TAX-CHECKER: HOW TO RUN IT
==========================

ONE FILE: "Tax Checker.bat"
---------------------------
Double-click "Tax Checker.bat". The first time on a PC it installs what the tool needs (a few minutes,
in a black window), then the Tax Checker window opens. Next times the window opens straight away.
Everything is in that window. It always shows the NEXT STEP with one big button:

1. Choose the supplier workbook (it's never changed; results go in a copy next to it).
2. "Check setup" (about 2 minutes, first time): checks the government sites, the browser and a few
   real lookups on your workbook. It creates no results.
3. "Start the full check": runs by itself for a few hours and keeps the PC awake (leave it on and on
   the network/VPN). Saskatchewan first: a browser window opens; tick "I agree" and "I'm not a robot",
   click Next (5 minutes to do it). Up to 100 Saskatchewan searches then run by themselves, then
   everything else. The window shows progress, the time left, and what to do if anything needs you.
4. If it stopped (Stop button, restart, network drop): the button becomes "Continue the stopped
   check". Finished suppliers are kept; ones with errors are tried again.
5. Saskatchewan, the next days (the registry allows 100 searches a day): open the window once a day;
   it says how many are done and when the next batch is possible. Click "Run today's Saskatchewan
   batch" and tick the CAPTCHA (about 20 minutes). Repeat until it says all are done.
6. "Add the Saskatchewan answers to the results" (once, no CAPTCHA): puts them in the results workbook.
7. "Open results" opens <workbook>_tax_check.xlsx.

Options (tick "Show options"): which taxes, Saskatchewan during the full check (untick to leave it all
to the daily batches), GST/HST registration dates (Quick recommended; Full is slower), and a paid-since
cut-off (blank = check everyone; ask the tax lead). The window remembers them.

"More" has the other jobs: start a new full check from the beginning, a 25-supplier trial, the
offline check (number formats only, no lookups), the workbook profile (for tailoring; no names or
numbers), the one-click test on public test data (sends back TaxCheck_Test_Results_<date>.zip),
Open results and Open logs folder.

If the tool is in a synced cloud folder, copy it to a local folder (e.g. Downloads) first. Always use
the same Tax-Checker folder until the Saskatchewan batches are done (their answers are kept in its
"cache" folder for 60 days).

The "advanced" folder has the older one-job .bat files (Run Tax Check, Resume Last Run, Run
Saskatchewan Batch, Test Setup, Run Test, Offline Check, Profile Workbook, Trial, Saskatchewan Probe).
They still work and do the same as the window's buttons; you don't need them. "advanced\Test
Setup.bat" also repairs the install if something is broken.

READING THE RESULTS
-------------------
- Start with the "Action List" sheet: only suppliers that need something done, worst first,
  with the Main Issue and the Action Needed for each.
- On the main sheet every result column has a filter. Filter "Main Issue" or "GST/HST Issue"
  to work through one kind of problem at a time (e.g. "Registered under another name").
- README.md lists every column and every Issue value.
- Overall: OK / REVIEW / NOT APPLICABLE (foreign supplier).
- Vendor Name Check: MATCHES / UPDATE NAME (correct the vendor record to the name in the
  GST/HST details) / NOT CONFIRMED (get the legal name from the supplier).
- Tax Check Summary sheet: counts and notes for the run.
- Your workbook is never changed; results are a new file in the same folder.
- Copies of every log go to your diagnostics folder, if you set one up (see diagnostics_dir.example.txt).
